# Exploratory Data Analysis (EDA) Report

## Objective
Perform exploratory data analysis on the Titanic dataset to identify patterns and trends.

## Dataset
Titanic Passenger Dataset

## Analysis Performed
- Checked dataset structure
- Generated statistical summary
- Identified missing values
- Analyzed survival distribution
- Analyzed gender distribution
- Examined correlations among numerical features

## Key Findings
- More passengers did not survive than survived.
- Male passengers were more common than female passengers.
- Age contained some missing values.
- Passenger class had an influence on survival.

## Tools Used
- Python
- Pandas
- Matplotlib

## Conclusion
EDA helped identify important patterns and trends within the dataset.
